# Yuref — Kickstarter Referrer Report

纯前端、单文件、零依赖的 Kickstarter 渠道（Referrer）拆分分析工具。

把 Kickstarter 后台导出的 referrers CSV 丢进去，自动按渠道分类、按周拆分、算周环比、画图表，再一键下载成独立 HTML 报表发给团队。

## ✨ 特性

- **零后端 / 零依赖**：单个 `report_tool.html`，浏览器直接打开即用，无需安装、无需联网、无构建步骤。
- **数据不出本机**：CSV 与归类规则只存在你当前浏览器的 localStorage，刷新自动恢复，绝不上传任何服务器（包括本公开仓库）。
- **多项目管理**：按项目归档报表（如 `heygears`、`heygears g1`），切换项目即恢复对应数据。
- **智能分类**：内置换 10 类渠道规则；未命中项进入「⚠️ 待确认」区，可搜索后一键归类。
- **周维度拆分**：按项目上线日自动识别首周，支持任意两周「等天数」环比（默认上周 vs 本周）。
- **可视化报表**：堆叠柱 + 分组柱 SVG 图表，自动缩放防截断；表格点表头即可按列排序。
- **一键导出**：生成带图表的完整 HTML 报表，离线可看、可直接转发同事。

## 🚀 快速开始（本地）

直接用浏览器打开 `report_tool.html` 即可，无任何前置条件。

## 📋 使用说明

1. **打开链接**：使用 GitHub Pages 在线版本，无需下载安装。
2. **选择项目**：顶部下拉选择已有项目，或新建一个项目归档你的报表。
3. **上传数据**：把 Kickstarter 后台导出的 Referrers CSV 拖进上传区；若无法上传，也可将 CSV 文本粘贴到文本框后点击「生成报表」。
4. **查看报表**：工具自动生成渠道拆分、周趋势、周环比与待确认归类四块报表。
5. **调整分类**：未命中规则的来源会进入「⚠️ 待确认」，可在「分类调整」里搜索并归到对应类别或「其他」。
6. **下载留档**：点击「下载报表 HTML」可导出带图表的独立 HTML 文件，离线可查看。

## 📑 CSV 格式要求

Kickstarter 后台 **Referrers** 导出，列为：

| Referrer | Date | Type | # of Pledges | % | Pledged |
|----------|------|------|--------------|---|---------|
| ... | ... | Kickstarter / External | ... | ... | ... |

- `Date` 用于周拆分；`Type` 为 `Kickstarter` 时自动分类、不进待确认区。
- 表头需为英文原样（KS 导出默认即此格式）。
